# Tshaprint Solutions POS & Multi-Branch ERP

A robust, enterprise-grade Laravel Point of Sale (POS) and Enterprise Resource Planning (ERP) platform built for multi-store retail operations.

---

## Core Modules & Features

- **Multi-Branch Store Management:** Independent inventory tracking and sales for Main Branch, Branch 2, and Branch 3 with real-time branch switching for administrators.
- **Point of Sale (POS) Terminal:** Fast retail checkout, concise uniform SKUs (`ACC-SW-22`), instant search, barcode scanning, and thermal receipt generation.
- **Opening Stock Intake & Spreadsheet Import:** Batch import physical inventory from Microsoft Excel / CSV spreadsheets with automated variant matching and audit logs.
- **Inter-Branch Stock Transfers:** Dual-stage dispatch workflow with customizable record dates and recipient confirmation (`Pending` &rarr; `Received`).
- **Role-Based Access Control (RBAC):** Granular Spatie permission matrices for Owners, Admins, Branch Managers, Cashiers, and Tailors.
- **Financial & Operational Reporting:** Dedicated independent reports for Profit & Loss, Sales Trends, Expenses, and Tax.
- **Anti-Tamper Operational Clock:** Centralized business clock preventing workstation time manipulation.
